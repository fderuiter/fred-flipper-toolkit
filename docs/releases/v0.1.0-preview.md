# FRED v0.1.0-preview

Released 2026-10-16. **Preview: not device-verified, not production-ready.**

FRED gives Claude Code four Flipper Zero skills that share one source-grounded rule set. The skills cover feasibility and compatibility, native FAP development, lifecycle/concurrency/parser review, and build/migration/release evidence. The baseline is official firmware 1.5.1 (`9e810dc`), target f7, API 88.2.

## Install

```sh
git clone https://github.com/fderuiter/fred-flipper-toolkit.git
cd fred-flipper-toolkit
git checkout v0.1.0-preview
python3 scripts/fred_setup.py        # Windows: py -3 scripts\fred_setup.py
```

See [Getting started](../GETTING-STARTED.md). The wizard shows each change and asks before making it, and `--dry-run` previews without changing anything. Restart Claude Code after installing.

## Known gaps

- SDK-migration task family scores 74.3, below the 80 floor ([#21](https://github.com/fderuiter/fred-flipper-toolkit/issues/21)).
- One critical teardown bug in a FRED pilot session ([#22](https://github.com/fderuiter/fred-flipper-toolkit/issues/22)).
- Paired improvement +9.5, just under the +10 gate ([#23](https://github.com/fderuiter/fred-flipper-toolkit/issues/23)).
- Token use is 1.75× baseline, over the 1.5× budget ([#13](https://github.com/fderuiter/fred-flipper-toolkit/issues/13)).
- Held-out validation is pending ([#12](https://github.com/fderuiter/fred-flipper-toolkit/issues/12)).
- The setup wizard has been tested on Ubuntu only ([#15](https://github.com/fderuiter/fred-flipper-toolkit/issues/15)).
- No device qualification yet ([#9](https://github.com/fderuiter/fred-flipper-toolkit/issues/9)).
- JavaScript, firmware, host and companion-MCU guidance is feasibility-level only. Forks (Momentum, Unleashed, Xtreme) are not supported.
