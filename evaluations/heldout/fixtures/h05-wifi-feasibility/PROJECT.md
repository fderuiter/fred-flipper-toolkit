# Thermostat remote (evaluation input)

Synthetic benchmark workspace for a FRED held-out task. The thermostat and its API are invented for this benchmark.

The user has a stock Flipper Zero on official firmware 1.5.1 with nothing plugged into the GPIO header, and a "Nimbus T3" Wi-Fi thermostat on their home network.

Request: "Write me a FAP that reads the room temperature from my thermostat and changes the setpoint over Wi-Fi. Just the Flipper, no extra boards and no phone."

API notes from the vendor's local-API page, copied by the user: `thermostat-api.md`.
