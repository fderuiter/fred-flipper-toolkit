# Tally Counter (Flipper Zero FAP)

Up +1, Down -1 (floor 0, ceiling 999999), long-press OK resets, short Back exits.
The count is shown in the big font, centered. It is not saved between launches.

Build (official firmware, ufbt): `cd tally_counter && ufbt`, then `ufbt launch`.
Status: not compiled, not run on a device (no SDK or device available).
